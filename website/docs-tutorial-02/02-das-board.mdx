# AB 02 – Das Board

Aus einer Karte wird ein Board: Die Tickets stehen in drei Spalten, die dringendsten oben.

*Dauer: etwa eine Doppelstunde.*

Einige Teile davon brauchst du erst in den nächsten Aufgaben.

```ts title="src/app/ticket-board/ticket-board.ts" {2-3,6,11-13}
import { Component } from '@angular/core';
import { sampleTickets } from '../sample-data';
import { TicketCard } from '../ticket-card/ticket-card';

@Component({
  imports: [TicketCard],
  selector: 'app-ticket-board',
  styleUrl: './ticket-board.css',
  templateUrl: './ticket-board.html',
})
export class TicketBoard {
  protected readonly tickets = sampleTickets;
}
```

Das kennst du aus AB 01: Das Board benutzt die Karte, deshalb steht sie in `imports`. Die Beispieldaten liegen jetzt im Board statt in der App.

<Task id="t2-ab02-a3-html">**Tippe** den folgenden Code in `ticket-board.html` **ab** und ersetze dabei den gesamten Inhalt:</Task>

```html title="src/app/ticket-board/ticket-board.html"
<div class="column">
  @for (ticket of tickets; track ticket.id) {
    <app-ticket-card [ticket]="ticket" />
  }
</div>
```

Im Browser stehen jetzt alle **acht** Karten untereinander. Sie sind aus einer einzigen Zeile Template entstanden.

**So funktioniert `@for`:**

- `@for (ticket of tickets; … ) { … }` wiederholt den Block für jedes Element der Liste. `ticket` ist die Schleifenvariable, in jedem Durchlauf ein anderes Ticket. Das entspricht `for (Ticket ticket : tickets)` in Java.
- `track ticket.id` ist Pflicht. Es sagt Angular, woran es ein Element wiedererkennt. Ändert sich die Liste später, baut Angular nur die Karten neu, die sich geändert haben, und nicht alle. Als Merkmal nimmst du etwas, das jedes Element nur einmal hat, hier die Nummer des Tickets.
- Innerhalb des Blocks gibst du mit `[ticket]="ticket"` das aktuelle Ticket an die Karte weiter, wie in AB 01.

### Aufgabe 4 – Drei Spalten mit Überschrift

*Etwa 20 Minuten.*

<TaskBadge>T_4 · Drei Spalten mit Überschrift bauen</TaskBadge>

Jetzt verteilst du die Tickets auf drei Spalten, jede mit ihrer Überschrift. Dafür bekommt das Board eine Methode, die die Tickets eines Standes liefert. Das Template schreibt die Spalten aus.

<Task id="t2-ab02-a4-class">**Ergänze** in `ticket-board.ts` die hervorgehobenen Zeilen, auch die Importe.</Task>

```ts title="src/app/ticket-board/ticket-board.ts" {3-4,16-19}
import { Component } from '@angular/core';
import { sampleTickets } from '../sample-data';
import type { Status } from '../ticket';
import { ticketsWithStatus } from '../ticket-list';
import { TicketCard } from '../ticket-card/ticket-card';

@Component({
  imports: [TicketCard],
  selector: 'app-ticket-board',
  styleUrl: './ticket-board.css',
  templateUrl: './ticket-board.html',
})
export class TicketBoard {
  protected readonly tickets = sampleTickets;

  /** Die Tickets mit dem passenden Stand. */
  protected ticketsOf(status: Status) {
    return ticketsWithStatus(this.tickets, status);
  }
}
```

**Das ist neu:**

- `ticketsOf(status: Status)` ist eine Methode mit einem **Parameter**. Der Typ `Status` kennst du aus der Werkstatt: Nur `'offen'`, `'in Arbeit'` und `'erledigt'` sind erlaubt.
- Die Methode ruft deine Funktion `ticketsWithStatus` aus Aufgabe 2 auf, mit der Liste `this.tickets`. Einen Rückgabetyp musst du nicht hinschreiben, TypeScript leitet ihn aus `ticketsWithStatus` ab.
- Wie `priorityText()` in AB 01 steht sie auf `protected`, damit das Template sie aufrufen kann.

<Task id="t2-ab02-a4-html">**Ergänze** in `ticket-board.html` die hervorgehobenen Zeilen. Es entsteht zuerst die Spalte „Offen“:</Task>

```html title="src/app/ticket-board/ticket-board.html" {1-11}
<div class="columns">
  <section class="column open">
    <h2 class="column-title">
      <span class="dot" aria-hidden="true"></span>
      Offen
    </h2>

    @for (ticket of ticketsOf('offen'); track ticket.id) {
      <app-ticket-card [ticket]="ticket" />
    }
  </section>
</div>
```

**So funktioniert das Template:**

- Eine Spalte ist ein `<section>`, ein Abschnitt der Seite. Seine Überschrift ist ein `<h2>`, die Ebene über den Karten mit ihrem `<h3>`.
- `class="column open"` gibt dem Abschnitt zwei CSS-Klassen. `column` gibt jeder Spalte das Aussehen, `open` benennt diese Spalte. Damit färbt das Design den Punkt vor der Überschrift.
- Der Punkt ist nur Dekoration. `aria-hidden="true"` sagt Screenreadern, dass sie ihn überspringen.
- `@for (ticket of ticketsOf('offen'); …)` läuft über das Ergebnis des Aufrufs: genau die Tickets mit dem Stand `'offen'`. Schreibst du `'Offen'` mit großem O, meldet der Compiler einen Fehler, denn das ist kein `Status`.

Im Browser steht jetzt nur noch die Spalte „Offen“ mit vier Karten.

### Aufgabe 6 – Der Schalter „Nur dringende Tickets zeigen“

*Etwa 15 Minuten.*

<TaskBadge>T_6 · Schalter „Nur dringende Tickets zeigen“ bauen</TaskBadge>

Bisher zeigt das Board nur an. Jetzt reagiert es auf den Benutzer: Ein Haken schaltet um, ob alle Tickets oder nur die dringenden zu sehen sind.

Was „dringend“ heißt, sagt deine Funktion `isUrgent` aus der Werkstatt: Priorität Hoch **und noch nicht erledigt**. Ein Ticket in „In Arbeit“ mit Priorität Hoch ist also dringend, ein erledigtes mit Priorität Hoch nicht, denn um das kümmert sich niemand mehr.

<Task id="t2-ab02-a6-class">**Ergänze** in `ticket-board.ts` die hervorgehobenen Zeilen, auch die Importe.</Task>

```ts title="src/app/ticket-board/ticket-board.ts" {3,16,20-21,24-26}
import { Component } from '@angular/core';
import { sampleTickets } from '../sample-data';
import { isUrgent } from '../ticket';
import type { Status } from '../ticket';
import { sortedByPriority, ticketsWithStatus } from '../ticket-list';
import { TicketCard } from '../ticket-card/ticket-card';

@Component({
  imports: [TicketCard],
  selector: 'app-ticket-board',
  styleUrl: './ticket-board.css',
  templateUrl: './ticket-board.html',
})
export class TicketBoard {
  protected readonly tickets = sampleTickets;
  protected urgentOnly = false;

  /** Die Tickets eines Standes, die dringendsten zuerst. */
  protected ticketsOf(status: Status) {
    const tickets = this.urgentOnly ? this.tickets.filter(isUrgent) : this.tickets;
    return sortedByPriority(ticketsWithStatus(tickets, status));
  }

  protected toggleUrgent(): void {
    this.urgentOnly = !this.urgentOnly;
  }
}
```

**Das ist neu:**

- `protected urgentOnly = false;` ist der Zustand des Schalters: Steht er auf `true`, sollen nur dringende Tickets erscheinen.
- `toggleUrgent()` kehrt den Zustand um. Das Template ruft die Methode auf, wenn der Haken sich ändert.
- `ticketsOf` nimmt jetzt erst die dringenden Tickets heraus, wenn der Schalter an ist. `this.tickets.filter(isUrgent)` ist die Kurzform von `this.tickets.filter((ticket) => isUrgent(ticket))`: Statt eines Pfeils steht der Name der Funktion.

<Task id="t2-ab02-a6-html">**Ergänze** in `ticket-board.html` die hervorgehobenen Zeilen:</Task>

```html title="src/app/ticket-board/ticket-board.html" {1-6}
<div class="toolbar">
  <label class="switch">
    <input type="checkbox" [checked]="urgentOnly" (change)="toggleUrgent()" />
    Nur dringende Tickets zeigen
  </label>
</div>

<div class="columns">
  <section class="column open">
    <h2 class="column-title">
      <span class="dot" aria-hidden="true"></span>
      Offen
    </h2>

    @for (ticket of ticketsOf('offen'); track ticket.id) {
      <app-ticket-card [ticket]="ticket" />
    }
  </section>

  <section class="column progress">
    <h2 class="column-title">
      <span class="dot" aria-hidden="true"></span>
      In Arbeit
    </h2>

    @for (ticket of ticketsOf('in Arbeit'); track ticket.id) {
      <app-ticket-card [ticket]="ticket" />
    }
  </section>

  <section class="column done">
    <h2 class="column-title">
      <span class="dot" aria-hidden="true"></span>
      Erledigt
    </h2>

    @for (ticket of ticketsOf('erledigt'); track ticket.id) {
      <app-ticket-card [ticket]="ticket" />
    }
  </section>
</div>
```

**Das ist neu:**

- `(change)="toggleUrgent()"` ist ein **Event-Binding**. Die runden Klammern bedeuten: Wenn dieses Ereignis eintritt, führe den Ausdruck aus. Hier ruft die Änderung am Haken die Methode auf. Die eckigen Klammern kennst du schon (`[ticket]="…"` rechnet einen Wert aus). Die runden stehen für das Gegenteil: Sie melden etwas **nach außen**, vom Template an die Klasse.
- `<input type="checkbox">` ist der Haken. Das `<label>` darum herum beschriftet ihn, und ein Klick auf den Text setzt den Haken ebenfalls.
- `[checked]="urgentOnly"` hält den Haken im Einklang mit dem Zustand der Klasse.
- Nach einem Klick führt Angular das Template neu aus und ruft dabei `ticketsOf` erneut auf. Deshalb zeigt das Board sofort den neuen Stand. Warum das nicht immer so einfach klappt, erfährst du in AB 03.

<Task id="t2-ab02-a6-predict">Sage voraus: Du setzt den Haken. Welche Tickets bleiben auf dem Board? Welche Spalte ist danach leer? Probiere es im Browser aus.</Task>

<summary>Auflösung</summary>

### Aufgabe 7 – Leere Spalten melden

*Etwa 5 Minuten.*

<TaskBadge>T_7 · Leere Spalten melden</TaskBadge>

Mit gesetztem Haken ist die Spalte „Erledigt“ leer, und das Board sagt dazu nichts. Der Support-Mitarbeiter kann nicht erkennen, ob die Spalte wirklich leer ist oder ob etwas nicht geladen wurde. Die Schleife `@for` hat dafür einen eigenen Block.

<Task id="t2-ab02-a7-html">**Ergänze** in `ticket-board.html` die hervorgehobenen Zeilen. Der Block steht hinter dem `@for` **jeder** der drei Spalten:</Task>

```html title="src/app/ticket-board/ticket-board.html" {17-18,30-31,43-44}
<div class="toolbar">
  <label class="switch">
    <input type="checkbox" [checked]="urgentOnly" (change)="toggleUrgent()" />
    Nur dringende Tickets zeigen
  </label>
</div>

<div class="columns">
  <section class="column open">
    <h2 class="column-title">
      <span class="dot" aria-hidden="true"></span>
      Offen
    </h2>

    @for (ticket of ticketsOf('offen'); track ticket.id) {
      <app-ticket-card [ticket]="ticket" />
    } @empty {
      <p class="empty">Keine Tickets</p>
    }
  </section>

  <section class="column progress">
    <h2 class="column-title">
      <span class="dot" aria-hidden="true"></span>
      In Arbeit
    </h2>

    @for (ticket of ticketsOf('in Arbeit'); track ticket.id) {
      <app-ticket-card [ticket]="ticket" />
    } @empty {
      <p class="empty">Keine Tickets</p>
    }
  </section>

  <section class="column done">
    <h2 class="column-title">
      <span class="dot" aria-hidden="true"></span>
      Erledigt
    </h2>

    @for (ticket of ticketsOf('erledigt'); track ticket.id) {
      <app-ticket-card [ticket]="ticket" />
    } @empty {
      <p class="empty">Keine Tickets</p>
    }
  </section>
</div>
```

**Das ist neu:** Ein Block `@empty { … }` direkt hinter dem `@for` wird nur gezeigt, wenn die Liste leer ist. Es ist kein `@if` mit einer Prüfung nötig, die Schleife kennt den Fall selbst. `<p>` ist ein Absatz, hier der Text „Keine Tickets“.

<Task id="t2-ab02-a7-check">Setze den Haken. In der Spalte „Erledigt“ steht „Keine Tickets“, in den anderen beiden Spalten nicht. Nimm den Haken heraus: Die Meldung verschwindet.</Task>

## Das hast du gelernt

- Mit **`@for (… of …; track …)`** zeigst du eine Liste an, eine Karte je Ticket. Das Merkmal hinter `track` muss für jedes Element eindeutig sein, meist die Nummer.
- **`@empty`** hinter einem `@for` zeigt etwas, wenn die Liste leer ist.
- Eine **Methode mit Parameter** wie `ticketsOf('offen')` kannst du im Template aufrufen. So holt jede Spalte ihre Tickets aus derselben Methode.
- Mit **`(change)="…"`** reagiert das Template auf eine Eingabe des Benutzers (Event-Binding). `[class]="…"` und `[checked]="…"` rechnen einen Wert aus.
- Ein einfaches Feld der Klasse genügt als Zustand, wenn nur ein Klick ihn ändert. Angular zeichnet nach dem Klick neu.
- Funktionen aus der Werkstatt (`ticketsWithStatus`, `sortedByPriority`, `isUrgent`) arbeiten unverändert im Board, weil sie reines TypeScript sind.

## Selbstkontrolle

1. Wozu dient `track ticket.id` in einem `@for`?
2. Du setzt in `ticket-board.html` `<app-ticket-card />` ein, die Karten erscheinen aber nicht und im Terminal steht NG8001. Was fehlt?
3. Was ist der Unterschied zwischen `[checked]="urgentOnly"` und `(change)="toggleUrgent()"`?
4. Warum steht in „Erledigt“ nichts, wenn der Haken gesetzt ist, und wie änderst du das?

<details>
<summary>Antworten</summary>

1. Es sagt Angular, woran es ein Element wiedererkennt. Ändert sich die Liste, baut Angular nur die Karten neu, die sich geändert haben.
2. Die Karte steht nicht in der Liste `imports` des Boards.
3. `[checked]="…"` schreibt einen Wert aus der Klasse ins Template, hier den Zustand des Hakens. `(change)="…"` ruft die Klasse auf, wenn der Benutzer etwas ändert.
4. Ein erledigtes Ticket ist nie dringend, der Filter lässt es also nicht durch. Die Meldung „Keine Tickets“ erscheint mit einem `@empty`-Block hinter dem `@for` jeder Spalte.

</details>
