# Infoblätter

Infoblätter erklären, was hinter einer Aufgabe steckt: Begriffe, Hintergründe und Vergleiche mit Java. Du musst sie **nicht vorher lesen**. Im Arbeitsblatt steht an der passenden Stelle ein Link, wenn dir etwas fehlt. Hier findest du alle auf einen Blick, zum Nachschlagen.

| [Listen auswerten: Array-Methoden](/infoblaetter/array-methoden) | Pfeilfunktionen, `filter`, `map`, `find`, `reduce` und `sort` – welche Methode wofür |

| [Klassen in TypeScript](/infoblaetter/klassen) | Aufbau, Konstruktor-Attribute, die Falle mit `this` – und was anders ist als in Java |
